Dépose ici tes nouvelles captures (png / jpg / webp, idéalement < 500 Ko).
Les captures PlayOff sont dans public/screenshots/.

Dans src/data/content.js, ajoute dans le bloc concerné :
  images: [
    { src: '/images/dcartes/mon-fichier.png', alt: 'Description pour l\'accessibilité', caption: 'Ma légende' },
  ],
Une vidéo mp4 : { src: '/screenshots/demo.mp4', poster: '/screenshots/image.png', caption: 'Démo' }
Une vidéo Loom : { loom: 'https://www.loom.com/share/xxxxxxxx', caption: 'Démo' }
Captures de téléphone (étroites) : ajoute  imagesNarrow: true  dans le bloc.
